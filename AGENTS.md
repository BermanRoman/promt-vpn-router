# Работа с promt-vpn-router

Это переносимая система по личному опыту настройки домашнего VPN.

README объясняет результат и старт простым языком, а технические подробности находятся в references.

Не превращать первую страницу в обещание настройки одной кнопкой или в перечень пугающих ограничений.

Для Mac без Ethernet явно включать гигабитный USB‑C–Ethernet и кабель в покупки до прошивки, чтобы основной сценарий не требовал старого роутера как моста.

Для настройки сети читать SKILL.md и хранить case, доступы и резервные копии вне этого репозитория.

Для разработки комплекта сохранять разделение: роли и runbooks направляют агента, scripts/case.py проверяет только ручной журнал, а реальные измерения выполняются при отдельной установке.

Не добавлять реальные адреса инфраструктуры, SSID, идентификаторы клиентов, ключи, подписки, документы, сырые журналы или личные абсолютные пути.

Партнёрские ссылки автора сохранять точно, новые условия и скидки проверять по первоисточникам.

Опыт автора без запроса документов не превращать в обещание отсутствия KYC.

До публикации запускать офлайн-тесты, проверку состава и относительных ссылок, затем проверять staged diff.
