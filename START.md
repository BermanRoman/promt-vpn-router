# Как запустить систему

Распакуйте папку `home-vpn-agent` на своём компьютере и откройте её агенту с доступом к локальным файлам, терминалу и интернету.

В Codex папку можно поместить в каталог пользовательских навыков; в другом инструменте передайте агенту файл `SKILL.md` как инструкцию для этой задачи.

Наличие файлов ролей не означает, что инструмент поддерживает субагентов: при их отсутствии главный агент работает последовательно.

Отправьте ему:

```text
Прочитай SKILL.md и собери мою домашнюю VPN-сеть по этой системе.
Сначала выясни мои задачи, текущую сеть и оборудование, затем создай отдельный локальный case и план.
Пароли и ключи в чат не запрашивай.
Перед покупкой или прошивкой проверь конкретный товар и способ восстановления.
Доведи работу до проверки на моём устройстве и передай мне резерв и инструкцию восстановления.
```

Не покупайте всё из списка заранее: сначала агент проверяет совместимость и достаточность уже имеющихся ресурсов.

Базовый вариант — российские адреса напрямую, остальные через Нидерланды.

Отдельная страна для выбранного сервиса, например Турция для Claude, требует дополнительной ноды, отдельной проверки условий сервиса и теста блокировки при отказе этой ноды.

Покупка VPS и домена не включает автоматически их настройку, допустимость VPN у провайдера или принятие IP конкретным сервисом.

Для Mac без Ethernet-разъёма заранее купите USB‑C → Ethernet на 1 Гбит/с и сетевой кабель: переходная прошивка Cudy отключает Wi-Fi.

Альтернативу через старый роутер агент сначала проверяет, а не обещает доступ после прошивки по названию модели.

Команды `scripts/case.py` ведут локальный журнал; они сами не подключаются по SSH, не оплачивают услуги и не меняют сеть.

Папку конкретного case, файлы SSH и резервные копии не пересылайте вместе с этим комплектом.
